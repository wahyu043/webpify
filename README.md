   # ⚡ Webpify

   Convert images to WebP right in your browser. Fast, private, and no uploads.

   > **Live:** https://webpify.wahyumahmudi.com
   > **Bahasa Indonesia:** Panduan teknis dan manfaat SEO lengkap ada di [DOKUMENTASI.md](./DOKUMENTASI.md).

   A client-side web app that converts and compresses images (PNG, JPEG, GIF, BMP, etc.) into Google's WebP format using the HTML5 Canvas API. Your files never leave your device.

   > 🤖 **About this project:** the first version was generated as a one-shot prototype with Google AI Studio, then customized and maintained by me.

---

## ✨ Features

- **Batch Conversion:** Drop multiple files at once.
- **Pure Client-Side Processing:** No server overhead. Safe and serverless.
- **Configurable Quality Slider:** Perfect compression sweet spot at 75% for ideal SEO rankings and file size reduction.
- **Instant Reduction Analytics:** Active visual counters listing original vs converted sizes and exact bandwidth savings percentages.
- **Dark Theme:** Dark interface with green accents, JetBrains Mono for numbers, and readable text sizes.
- **Batch Downloading:** Trigger sequential automatic downloads for the entire queue with a single click.

## 🚀 Quick Start

### Installation
Install project dependencies:
```bash
npm install
```

### Run Locally (Dev Mode)
Boot up the local development web server:
```bash
npm run dev
```

### Production Build
Compile and bundle static files into `/dist/` optimized for static hostings (Vercel, Netlify, Github Pages, or your own Nginx VPS directory):
```bash
npm run build
```
