# ⚡ WebP Image Converter (High-Performance Client-Side Optimizer)

A highly polished, responsive client-side web application designed to convert and compress digital images (PNG, JPEG, GIF, BMP, etc.) into modern Google WebP format. No image data is uploaded to external servers—100% locally optimized in the browser using HTML5 Canvas.

> **Bahasa Indonesia:** Dokumen panduan teknis, fitur, dan manfaat SEO lengkap tersedia di file [DOKUMENTASI.md](./DOKUMENTASI.md).

---

## ✨ Features

- **Batch Conversion:** Drop multiple files at once.
- **Pure Client-Side Processing:** No server overhead. Safe and serverless.
- **Configurable Quality Slider:** Perfect compression sweet spot at 75% for ideal SEO rankings and file size reduction.
- **Instant Reduction Analytics:** Active visual counters listing original vs converted sizes and exact bandwidth savings percentages.
- **Aesthetic Cyberpunk Slate Theme:** Smooth dark interface built with custom Montserrat headings, JetBrains Mono data values, and sleek emerald green accents.
- **Batch Downloading:** Trigger sequential automatic downloads for the entire queue with a single click.

## 🚀 Quick Start

### Installation
Install project dependencies:
```bash
npm install
```

### Run Locally (Dev Mode)
Boot up the local development web server:
```bash
npm run dev
```

### Production Build
Compile and bundle static files into `/dist/` optimized for static hostings (Vercel, Netlify, Github Pages, or your own Nginx VPS directory):
```bash
npm run build
```
